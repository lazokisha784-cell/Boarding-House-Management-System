# Boarding House Management System

A responsive, full-featured web application for managing rooms, tenants, rent payments, maintenance requests, and financial reports.

## Features
- **Admin Authentication**: Secure login and logout session management.
- **Interactive Dashboard**: Room occupancy rate and rental income summary metrics.
- **Room Management**: Track room numbers, capacity, monthly rent, and live occupancy status.
- **Tenant Management**: Record tenant profiles, emergency contacts, move-in dates, and room assignments.
- **Rent Payment Tracking**: Track payment dates, due dates, payment methods, and overdue balances.
- **Maintenance Requests**: Monitor room issues, priority levels, and repair status.
- **Reports & Analytics**: Printable summary reports for revenue, rooms, and tenant records.
- **Persistent Database**: SQLite database for local and server deployment.

## Technology Stack
- **Backend**: Python 3.9+ & Flask
- **Database**: SQLite (SQLAlchemy ORM)
- **Frontend**: Responsive HTML5, Modern Vanilla CSS, and Vanilla JavaScript
- **Version Control**: Git & GitHub

## Getting Started

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the application**:
   ```bash
   python app.py
   ```

3. **Open in browser**:
   Navigate to `http://127.0.0.1:5000`

Default admin credentials:
- **Username:** `admin`
- **Password:** `admin123`
